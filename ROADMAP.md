# 🚀 Rockpload Roadmap

## Vision
Rockpload aims to become a powerful multi-platform Rocket League replay manager:
- Upload replays to multiple services simultaneously
- Track multiple accounts and matches in real-time
- Provide live and post-game statistics


## 🌐 v2.0.0 – Multi Upload System
> Inspired by Ballchasing-like workflow

- [ ] Create "Upload Provider" interface
- [ ] Implement Ballchasing provider
- [ ] Add support for multiple simultaneous uploads
- [ ] Queue system for uploads
- [ ] Retry mechanism on failure

### Future providers
- [ ] Custom API endpoints
- [ ] Local storage / backup
- [ ] Community platforms

---

## 👥 v3.0.0 – Multi Account Tracking
> Manage multiple Rocket League profiles

- [ ] Support multiple account identifiers
- [ ] Track replays per account
- [ ] Add account config system
- [ ] Auto-detect active account

---

## 📡 v4.0.0 – Live Match Tracking
> Real-time match monitoring

- [ ] Detect active match from StatsAPI
- [ ] Parse match events in real time
- [ ] Send live stats to API

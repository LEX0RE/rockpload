# Security Policy

## Supported Versions

Security updates are provided for the latest release line.

## Reporting a Vulnerability

Please report vulnerabilities privately using GitHub's private vulnerability
reporting for this repository.

Do not open public issues for security vulnerabilities.

After receiving a report, maintainers will:

- Acknowledge receipt as soon as possible
- Investigate and validate the report
- Prepare and release a fix when confirmed
- Credit the reporter when appropriate
